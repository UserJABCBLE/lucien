GitHub 연결

게시하려면 이 저장소에 글을 저장할 수 있는 열쇠(토큰)가 필요해요. 열쇠는 이 브라우저에만 저장되고 GitHub 말고 다른 곳으로는 보내지지 않아요.

토큰 만드는 법
  1. GitHub 오른쪽 위 프로필 사진 → Settings → 왼쪽 맨 아래 Developer settings
  2. Personal access tokens → Fine-grained tokens → Generate new token
  3. Token name: lucien-admin, Expiration: 원하는 기간 (길게 해도 돼요)
  4. Repository access: Only select repositories → lucien 하나만 선택
  5. Permissions → Repository permissions → Contents를 Read and write로
  6. 맨 아래 Generate token → 나온 열쇠를 복사해서 위 칸에 붙여넣기

열쇠는 다시 볼 수 없으니, 다른 기기에서도 쓰려면 안전한 곳(비밀번호 관리자 등)에 보관하세요. 남에게 보여 주지 마세요.

    구글 문서에서 본문 전체를 복사(Ctrl+A → Ctrl+C)해서 여기를 누르고 붙여넣으세요(Ctrl+V).
